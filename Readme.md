## 💡 Quick Code Snippet: Your First HTML5 Boilerplate

Here is a quick reference template to kickstart any web page project:

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Quantum Lab Portal</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <header>
        <h1>Welcome to Lab E-309</h1>
    </header>
    <main>
        <p>Let's build the web together!</p>
    </main>
    <script src="script.js"></script>
</body>
</html>
```
